VO PATCH EX — G03 PRIVATE WINDOWS UAT
0.1-dev. Requires 64-bit Windows. Physical acceptance pending. No upload or administrator rights.

Extract this ZIP to a writable folder. On first launch, choose your own pristine
Retail or Japanese rerelease game installation when prompted. Its v_on.exe and
original resource files must be present. The original folder is never modified.
A private working copy and verified rendering profiles are prepared automatically.
No game executables or assets are included in this ZIP. Preparation may take a
minute. No Python installation, compilation, DLL copying or INI editing is needed.

Run ONE at a time:
 START-SINGLE-DISPLAY.cmd
 START-DUAL-VERSUS.cmd
 START-DUAL-MIRROR.cmd
Review the display/aspect selection and click Launch. Session-only selections do
not overwrite saved display preferences. Missing dual outputs are reported before
startup; a fallback run is not a passing dual-display test. F-key menus continue
to control game/controller settings. Close the game normally after each test.

After exit (including launch failure), collection automatically creates/selects:
 RETURN-THIS-VO-PATCH-EX-G03.zip
EXPORT-DIAGNOSTICS.cmd retries collection independently. Original logs survive
export failures. The timestamped VO-PATCH-EX-Diagnostics-*.zip is the same export.
Return the stable ZIP with your observations; nothing is uploaded automatically.
Keep this private package and its prepared game folder off public repositories.

NORMAL diagnostics are automatic. DETAILED and DEVELOPMENT are optional explicit
launch arguments (--level DETAILED / --level DEVELOPMENT). Neither records raw
controller input. No level change is needed for the acceptance run.
