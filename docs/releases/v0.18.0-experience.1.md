# VO PATCH EX v0.18.0-experience.1 — Controllers + Display Expansion

Draft prerelease notes; not published.

VO PATCH EX expands Cyber Troopers Virtual-On for PC with dedicated Twin-Stick
profiles and configurable single- and dual-display presentation. It builds on
[Pairomaniac's V-On Patcher](https://github.com/pairomaniac/v-on-patcher), preserving
its installation workflow, original F-key menus, artwork, attribution and MIT license.
Controller and Display Expansion are maintained by hyp36rmax.

This is a private prerelease candidate. Physical Windows acceptance for this
integrated package remains pending; it is not a stable release.

## Controllers

F7 retains Gamepad (XInput), Twin-Stick (XInput), Twin-Stick (Custom), Tanita,
Xbox 360 HORI EX, Raphnet Dreamcast, Raphnet Saturn, Keyboard (Simple) and
Keyboard (Real). Players select profiles independently and claim their physical
controllers through the existing Start/Options assignment prompt. Supported
remapping, saved bindings and mixed-controller local versus play are preserved.
Custom uses one XInput-compatible controller; it does not aggregate separate joysticks.

Prior hardware validation is retained independently from acceptance of this package:

| Hardware/configuration | Recorded status |
|---|---|
| Implemented profiles | 1P and 2P validated; mixed local VS functionally tested |
| Dual Tanita | Functionally tested |
| Mixed Raphnet Dreamcast v1 / Saturn v2 | Functionally tested |
| Dual Xbox 360 HORI EX | Pending |
| Dual identical Raphnet DC / dual identical Saturn | Not tested |
| Raphnet Dreamcast v2 | Manufacturer-documented HKT-7500 support; local validation pending |

HORI findings apply to the Xbox 360 model, not the PlayStation model. Raphnet
characterization applies to the recorded adapter revisions. Unrecorded reconnect
permutations and persistence subtests remain unconfirmed.

## Displays

Use **F5 Graphic Settings → Display...** to select:

| Mode | Presentation |
|---|---|
| Single Display | One monitor, with 4:3, 16:9, 21:9 or 32:9 game aspect ratio |
| Dual Display Versus | Independent P1/P2 gameplay views on assigned monitors |
| Dual Display Mirror | Complete primary presentation duplicated, including both Local VS views |

Primary and secondary assignments support different desktop resolutions and aspect
ratios. Saved preferences survive temporary missing-monitor fallback. Local VS
selection is shared; movies use the primary display with the secondary black in
dual modes. Existing Local VS split settings and F4 resolution behavior remain.
Display changes apply on the next launch. Unsupported dual-mode F4 transitions
retain the supported presentation.

Fresh default installation uses 16:9 Single Display. Explicitly disabling the
high-resolution patch starts from original 4:3 unless saved Display settings
select another profile. The eight-display inventory records maintainer-validated configurations; it is
not an exclusive compatibility list or proof of every mode or monitor pairing.

## Installation and upgrades

1. Extract the complete ZIP and keep `_internal` beside `v-on-patcher.exe`.
2. Back up saved settings before upgrading. If the installation is already
   patched, use upstream **Restore Original** before applying this package.
3. Open **V-On Patcher EX**, select the original supported ISO/files, choose the
   existing patch options and select **Apply**. Keep XInput support enabled for
   expanded controller profiles and F11 Extras enabled for diagnostic controls.
4. Launch the installed `v_on.exe` normally. Configure controllers in F7 and
   displays in F5; restart after changing display settings.

The integrated recipe set is validated against English retail and Japanese
rerelease executables. No game executable or disc image is included. No separate
installer, mandatory game launcher, manual configuration editing or compilation
is required. Do not patch over an already patched executable.

## Diagnostics and privacy

Logging defaults to **Off**. F11 provides Off, Normal, Detailed and Development
levels and explicit local export. Restart after enabling logging. Selecting Off
stops new collection and retains existing logs. Nothing is uploaded automatically.

## Validation and limitations

Local automated validation passed 33 baseline checks, 13 targeted suites and 512
recipe reconstructions. Coverage includes controller regressions, display hooks
and geometry, Retail/JPRE patch recipes, Apply/Restore, privacy, branding and
package integrity. Physical launch, monitor presentation, controller interaction,
DPI/layout and restart persistence still require acceptance of this exact ZIP.
The earlier baseline failed complete Windows packaging. The checkout-policy
correction passed hosted CI, including Windows packaging, at Experience commit
`49a7e7359592d71e39c576ac3c1884bb5a80bb78` in
[run 38850298893](https://github.com/hyp36rmax/VO_PATCH_EX/actions/runs/38850298893).
That build result does not establish final physical Windows acceptance.

Controller ownership is session-scoped; saved profiles do not preserve physical
device identity across launches. After a detected disconnect, reselect in F7.
Native HID families reserve two device paths per process; additional USB paths may
require restarting the game. Fixed native mappings and supported hardware revisions
remain as documented. Universal monitor compatibility is not claimed.

Original F4, F5, F6, F7, F8 and F11 functions remain available. This candidate
contains the Controllers + Display experience only.
